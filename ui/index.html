怎么用

一键获取

  1. 在项目目录跑 node bridge.mjs，它只监听 127.0.0.1。
  2. 打开它给出的地址（默认 http://127.0.0.1:8787/）。
  3. 在顶部地址栏填你自己的本地页面地址，点获取 m3u8 地址。
  4. 它会开一个独立 profile 的浏览器窗口录请求；取到地址并解析完就自动收尾。
  5. 地址输出区每条右边都有复制，也可以一次复制全部或导出 .txt。

如果页面要你点一下才起播，去探针窗口里点一下；工具会等地址解析完再收尾，最长等待由「兜底收尾」决定。

判定有三条腿

  • url：地址里含 .m3u8
  • mime：响应类型是 mpegurl
  • body：响应体以 #EXTM3U 开头

第三条腿受 CDP 限制：页面 fetch 后没读过的响应体取不回来，这种只能靠前两条腿。

范围

这是"你自己驱动的浏览器 + localhost"的录制器。起始地址只接受 localhost / 127.0.0.1 / [::1]，不做批量抓取，也不面向第三方站点。

演示模式

没有本地桥接时（比如 GitHub Pages 上），页面用一份按当前配置生成的示例数据驱动， 所有控件照常可用，但不会真的启动浏览器。点随机示例换一批。

声音

默认关闭。你在调试音视频，突然响一声是干扰；需要盯命中时再打开顶栏的提示音。
